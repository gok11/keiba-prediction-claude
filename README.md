# 競馬予想システム (Keiba Prediction System)

機械学習を用いた競馬予想GUIアプリケーション

## 概要

このアプリケーションは、db.netkeiba.comから過去のレースデータを収集し、機械学習モデルで分析・予想を行うシステムです。

### 主な機能

- **データ収集**: db.netkeiba.comからの過去レースデータのスクレイピング
- **機械学習トレーニング**: LightGBM, XGBoost, RandomForestによる予測モデルの訓練
- **バックテスト**: 過去データを使用した予測精度とROIの検証
- **本番予想**: 未来のレースに対する予測実行

## 技術スタック

- **言語**: Python 3.10+
- **GUI**: PyQt6
- **機械学習**: LightGBM, XGBoost, scikit-learn
- **データ処理**: pandas, numpy
- **データベース**: SQLite3
- **スクレイピング**: requests, BeautifulSoup4

## セットアップ

### 1. リポジトリのクローン

```bash
git clone <repository-url>

```

### 2. 仮想環境の作成（推奨）


## 使い方

### 1. データベースの初期化

アプリケーション起動後、メニューバーから「ファイル」→「データベース初期化」を実行

### 2. データ収集

「データ収集」タブで:
- 期間を設定（例: 2020-01-01 ～ 2024-12-31）
- スリープ時間を設定（推奨: 2～5秒）
- 「スクレイピング開始」をクリック

**注意**: IPブロックを避けるため、適切なスリープ時間を設定してください

### 3. データ閲覧

収集したデータは以下の2つの方法で閲覧できます：

#### GUI（推奨）

「データ閲覧」タブで視覚的にデータを閲覧：

1. **レース一覧**
   - 期間を指定してレースを検索
   - レースをダブルクリックで詳細表示
   - 統計情報ボタンでデータベース統計を確認

2. **レース詳細ダイアログ**（タブ形式）
   - 基本情報：レース条件、グレード、賞金、馬場指数など
   - レース結果：着順、タイム、オッズ、馬体重など
   - 払戻金：各券種の払戻金と人気
   - ラップタイム：200m区間ごとのラップタイム
   - プレミアム情報：注目馬短評、レース分析コメント
   - **馬名をダブルクリック**で馬の詳細表示

3. **馬の詳細ダイアログ**
   - 基本情報：血統情報（父、母、母父）
   - 過去成績：全出走履歴をテーブル表示
   - 厩舎コメント：最新5件の調教コメント
   - **日付をダブルクリック**でレース詳細へ戻る

階層的な閲覧が可能で、レース ⇔ 馬の相互遷移ができます。

#### コマンドライン

コマンドラインで簡単に閲覧することもできます：

#### Windows:
```bash
# レース一覧を表示
view_data.bat list

# レース詳細を表示
view_data.bat race <レースID>

# 馬の過去成績を表示
view_data.bat horse <馬ID>

# データベース統計を表示
view_data.bat stats
```

#### Linux/Mac:
```bash
# レース一覧を表示
./view_data.sh list

# レース詳細を表示（例: レースID 202408030211）
./view_data.sh race 202408030211

# 馬の過去成績を表示（例: 馬ID 2012104324）
./view_data.sh horse 2012104324

# データベース統計を表示
./view_data.sh stats
```

#### Pythonスクリプト直接実行:
```bash
# レース一覧（期間指定）
python view_data.py list --start 2020-01-01 --end 2020-12-31

# レース詳細（ラップタイム、払戻金、プレミアム情報含む）
python view_data.py race 202408030211

# 馬の過去成績（最新10件）
python view_data.py horse 2012104324 --limit 10

# データベース統計
python view_data.py stats
```

### 4. モデルトレーニング

「トレーニング」タブで:
- 使用するモデルを選択（LightGBM推奨）
- ハイパーパラメータを調整
- 「トレーニング開始」をクリック

### 5. バックテスト

「バックテスト」タブで:
- 訓練済みモデルを選択
- テスト期間を設定
- 購入戦略を設定
- 「バックテスト実行」をクリック

### 6. 本番予想

「本番予想」タブで:
- 対象日を選択
- レース情報を取得
- 「予想実行」をクリック
