# 競馬予想システム (Keiba Prediction System)

機械学習を用いた競馬予想GUIアプリケーション

## 概要

このアプリケーションは、db.netkeiba.comから過去のレースデータを収集し、機械学習モデルで分析・予想を行うシステムです。

### 主な機能

- **データ収集**: db.netkeiba.comからの過去レースデータのスクレイピング
- **機械学習トレーニング**: LightGBM, XGBoost, RandomForestによる予測モデルの訓練
- **バックテスト**: 過去データを使用した予測精度とROIの検証
- **本番予想**: 未来のレースに対する予測実行

## 技術スタック

- **言語**: Python 3.10+
- **GUI**: PyQt6
- **機械学習**: LightGBM, XGBoost, scikit-learn
- **データ処理**: pandas, numpy
- **データベース**: SQLite3
- **スクレイピング**: requests, BeautifulSoup4

## セットアップ

### 1. リポジトリのクローン

```bash
git clone <repository-url>
cd keiba-prediction-claude
```

### 2. 仮想環境の作成（推奨）

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# または
venv\Scripts\activate  # Windows
```

### 3. 依存関係のインストール

```bash
pip install -r requirements.txt
```

### 4. アプリケーションの起動

```bash
python main.py
```

## 使い方

### 1. データベースの初期化

アプリケーション起動後、メニューバーから「ファイル」→「データベース初期化」を実行

### 2. データ収集

「データ収集」タブで:
- 期間を設定（例: 2020-01-01 ～ 2024-12-31）
- スリープ時間を設定（推奨: 2～5秒）
- 「スクレイピング開始」をクリック

**注意**: IPブロックを避けるため、適切なスリープ時間を設定してください

### 3. モデルトレーニング

「トレーニング」タブで:
- 使用するモデルを選択（LightGBM推奨）
- ハイパーパラメータを調整
- 「トレーニング開始」をクリック

### 4. バックテスト

「バックテスト」タブで:
- 訓練済みモデルを選択
- テスト期間を設定
- 購入戦略を設定
- 「バックテスト実行」をクリック

### 5. 本番予想

「本番予想」タブで:
- 対象日を選択
- レース情報を取得
- 「予想実行」をクリック
